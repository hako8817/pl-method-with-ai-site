# Proposal

수주형 프로젝트의 앞단에서 제안서를 기획 산출물로 다루는 섹션이다.

이 섹션은 RFP 분석, 요구사항 대응 구조화, 제안 전략, 제안서 작성 흐름을 중심으로 제안 작업을 구조화한다.

## What This Section Covers
- 제안서 작업의 앞단 구조
- 제안 자동화와 반자동화의 적용 지점
- 착수와 기획으로 넘어가는 입력 구조
